# v0.7.30 — Compartir himno completo

- **Compartir himno** envía siempre el texto completo del himno (todas las estrofas y coros), más número, título y fuente.
- La selección de estrofa únicamente activa la barra contextual; no limita el contenido compartido.
- **Copiar** mantiene su acción sobre la estrofa o coro seleccionado.
- El corazón del encabezado sigue guardando el himno completo.
- Sin cambios en datos JSON, favoritos o navegación bíblica.
- Versión de CSS y JavaScript actualizada para invalidar caché.
