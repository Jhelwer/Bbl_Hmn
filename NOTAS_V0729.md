# v0.7.29 — Acciones contextuales del Himnario

- Al abrir un himno, la barra inferior permanece oculta.
- Tocar una estrofa o el coro selecciona el fragmento y muestra Copiar/Compartir.
- Volver a tocar el fragmento o pulsar Cerrar oculta las acciones.
- El corazon en el encabezado guarda o quita el himno completo; no afecta a libros ni versiculos biblicos.
- Al navegar a otro himno se limpia la seleccion; modo lectura mantiene oculta la barra.
- Los favoritos de himnos siguen en la misma clave `himnos:<id>`.
- No se modifican JSON ni datos.
