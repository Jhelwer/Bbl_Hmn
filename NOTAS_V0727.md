# Biblia e Himnario v0.7.27 — Retomar lectura por versículo

- «Tu última lectura» muestra ahora Libro capítulo:versículo cuando existe una posición real guardada.
- «Continuar leyendo» restaura la posición vertical del versículo y el desplazamiento dentro del capítulo.
- El progreso bíblico se almacena en una clave separada para que abrir un himno no sobrescriba la última lectura de Biblia.
- Antes de cerrar el lector desde Atrás o Escape se conserva la última posición.
- Las seis traducciones disponibles se respetan al reanudar.
- Compatibilidad con historial anterior: cuando no hay versículo guardado se abre el capítulo correspondiente.
- Sin cambios en JSON, resaltados, favoritos o letras.
